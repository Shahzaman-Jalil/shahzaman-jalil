## 📂 Featured Projects

### 🚖 [OpsPulse — NYC Taxi ETL Pipeline](https://github.com/Shahzaman-Jalil/opspulse-nyc-taxi)

End-to-end ETL pipeline built on the NYC Yellow Taxi dataset (2.8M rows, Jan 2024).
Implements the **Medallion Architecture** (Bronze → Silver), cleans raw Parquet data, loads into **PostgreSQL**, runs 10 advanced SQL analytics queries (window functions, CTEs, HAVING), and validates data quality with **pytest**.

`Python` `PostgreSQL` `Pandas` `SQLAlchemy` `pytest` `Jupyter`

### 🏗️ [SQL Data Warehouse Project](https://github.com/Shahzaman-Jalil/sql-data-warehouse-project)
